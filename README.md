# CraftifAI PipeGen Track 1: Edge Vision Perception Pipeline

An optimized edge vision object detection pipeline built for the CraftifAI Physical AI Hackathon. This project utilizes a lightweight **YOLOv8n** model exported to ONNX format for high-speed perception tasks[cite: 2].

## 🚀 Project Overview
* **Track:** PipeGen (Perception)[cite: 1, 2]
* **Model Architecture:** YOLOv8n (Object Detection)
* **Format:** ONNX (`yolov8n.onnx`)
* **Target Environment:** NVIDIA GPU / Jetson Edge Hardware[cite: 2]
